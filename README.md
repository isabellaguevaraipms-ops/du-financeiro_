# DU — Controle Financeiro

Projeto web responsivo de controle financeiro pessoal.

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Os registros ficam salvos no `localStorage` do navegador.
4. Para usar o microfone, abra em um navegador compatível (Chrome/Edge normalmente funcionam melhor) e permita o acesso ao microfone.

## Recursos
- Dashboard com saldo, entradas e saídas.
- Cadastro manual de entradas/saídas.
- Assistente por texto e reconhecimento de voz.
- Interpretação de frases como “gastei 35 reais no mercado hoje”.
- Histórico com busca e filtros.
- Edição e exclusão.
- Análises por categoria.
- Calendário financeiro.
- Persistência local sem dados fictícios.
- Layout responsivo/mobile-first.

## Observação
Esta é uma versão front-end funcional e autocontida. O reconhecimento de voz usa a API de fala do navegador e pode depender do navegador/permissões. Os dados ficam apenas no navegador/dispositivo e não são sincronizados entre aparelhos.

A identidade visual usa referências de estética brasileira de forma abstrata e respeitosa; o personagem do assistente é apresentado como elemento ficcional da interface, sem afirmar representar práticas ou ensinamentos religiosos.
